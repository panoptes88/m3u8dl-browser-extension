# 常见问题

## 连接服务器失败

### 问题描述

点击「测试连接」提示连接失败。

### 可能原因

1. **服务器地址错误**
   - 检查地址是否正确（如 `http://192.168.1.100:8080`）
   - 确保包含协议头（`http://` 或 `https://`）

2. **服务器未启动**
   - 检查 Docker 容器是否运行：`docker ps`
   - 查看容器日志：`docker logs m3u8dl-web-ui`

3. **防火墙阻止**
   - 检查服务器防火墙是否开放 8080 端口
   - 检查云服务器安全组设置

4. **用户名密码错误**
   - 默认用户名：`admin`
   - 默认密码：`admin123`

5. **CORS 配置问题**
   - 确保设置了 `ALLOW_ORIGINS=*`
   - 重启容器使配置生效

## 资源不显示

### 问题描述

播放视频后，popup 窗口没有显示嗅探到的资源。

### 可能原因

1. **视频未播放**
   - 必须播放视频才能触发嗅探
   - 点击播放按钮，等待视频加载

2. **点击刷新**
   - 点击 popup 窗口的「刷新」按钮
   - 等待页面重新加载

3. **嗅探类型未启用**
   - 检查设置页面的「嗅探资源类型」
   - 确保需要的类型已勾选

4. **资源被忽略**
   - 某些 URL 会被忽略（如 Facebook、Twitter 等）
   - 这是正常行为

## 下载失败

### 问题描述

发送任务后，下载失败。

### 可能原因

1. **服务器连接问题**
   - 检查服务器是否正常运行
   - 查看服务器日志

2. **代理配置问题**
   - 检查代理是否可用
   - 尝试关闭代理测试

3. **资源需要认证**
   - 某些资源需要特定的请求头（如 Referer）
   - 插件会自动提取 Referer，但某些网站可能需要其他头

4. **网络问题**
   - 增加重试次数
   - 检查网络连接

## 翻译失败

### 问题描述

点击翻译按钮后，提示翻译失败。

### 可能原因

1. **API 配置错误**
   - 检查 API Base URL 是否正确
   - 检查模型 ID 是否正确
   - 检查 API Key 是否有效

2. **API 余额不足**
   - 检查 API 账户余额
   - 充值或更换 API

3. **网络问题**
   - 检查网络连接
   - 尝试使用代理

4. **查看详细错误**
   - 打开 popup 控制台（右键 → 检查）
   - 查看 `[翻译]` 开头的日志

## 预览失败

### 问题描述

点击预览按钮后，视频无法播放。

### 可能原因

1. **资源需要认证**
   - 某些资源需要特定的请求头
   - 插件会自动设置，但可能不完整

2. **资源已过期**
   - 某些资源有时效性
   - 刷新页面重新嗅探

3. **格式不支持**
   - 尝试使用其他播放器
   - 或直接下载

## 代理不生效

### 问题描述

开启代理后，下载仍然不走代理。

### 可能原因

1. **代理配置错误**
   - 检查代理地址和端口
   - 检查代理类型是否正确

2. **代理开关未开启**
   - 在 popup 窗口检查代理开关
   - 或在设置页面检查代理开关

3. **代理不可用**
   - 测试代理是否可用
   - 更换代理

## 插件图标不显示

### 问题描述

安装插件后，图标不显示或显示异常。

### 解决方法

1. 重新加载插件
   - 打开 `chrome://extensions/`
   - 点击插件的刷新按钮

2. 重启浏览器

3. 重新安装插件

## 数据丢失

### 问题描述

配置或嗅探记录丢失。

### 说明

- 嗅探记录存储在内存中，关闭 popup 或刷新页面会清除
- 配置保存在浏览器中，会自动同步
- 清除浏览器数据会丢失配置

## 调试方法

### 查看 Service Worker 日志

1. 访问 `chrome://extensions/`
2. 找到 m3u8DL Sniffer
3. 点击「Service Worker」链接
4. 在打开的 DevTools 中查看 Console 日志

### 查看 Popup 日志

1. 点击扩展图标打开 popup
2. 右键点击 popup 页面
3. 选择「检查」
4. 在打开的 DevTools 中查看 Console 日志

### 日志前缀

- `[m3u8DL]` - 主要功能日志
- `[翻译]` - 翻译功能日志
