# 插件安装

## 下载插件

### 方式一：从 GitHub 下载

```bash
git clone https://github.com/panoptes88/m3u8dl-browser-extension.git
```

### 方式二：下载 Release 包

从 [Releases](https://github.com/panoptes88/m3u8dl-browser-extension/releases) 页面下载最新版本的 zip 包，解压到本地目录。

## 安装插件

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择下载的插件目录

![Chrome 扩展管理页面](../images/chrome-extension-dev-mode.png)

## 配置服务器

### 打开设置页面

右键扩展图标 → 选择「选项」

![插件右键菜单](../images/plugin-right-click-menu.png)

### 配置远程服务器

在「远程服务器配置」中填写：

- **服务器地址**：`http://your-server-ip:8080`
- **用户名**：`admin`
- **密码**：`admin123`（或你设置的密码）

点击「测试连接」验证配置是否正确。

![服务器配置](../images/plugin-server-config.png)

### 保存配置

点击「保存配置」按钮。

## 配置代理（可选）

如果需要代理下载，在「代理配置」中：

1. 勾选「启用代理」
2. 填写代理类型、地址、端口
3. 如果需要认证，勾选「需要认证」并填写用户名密码

![代理配置](../images/plugin-proxy-config.png)

## 配置 AI 翻译（可选）

如果需要翻译视频标题，在「AI 翻译配置」中：

1. 勾选「启用 AI 翻译」
2. 填写 API Base URL（如 `https://api.gpt.ge`）
3. 填写模型 ID（如 `gpt-4o-mini`）
4. 填写 API Key
5. 自定义翻译提示词（可选）

点击「测试翻译」验证配置是否正确。

![AI 翻译配置](../images/plugin-translate-config.png)

## 验证安装

安装完成后，扩展图标会出现在浏览器工具栏中。点击图标可以打开插件窗口。
